# Edition 9 review guide

1. Can untrusted planner output name an action outside the server registry? It must not.
2. Can an Agent exceed the workspace domains granted by its existing capabilities? It must not.
3. Can any workspace mutation command be emitted without approval bound to the exact plan? It must not.
4. Did Edition 9 create a new direct database mutation path? It must not; execution remains delegated to the existing KIVRYN action executor.
