# Edition 9 scope boundary

Edition 9 establishes workspace action authority and orchestration contracts. It does not claim that the current OpenAI call is already running autonomous multi-step tool loops.

Real workspace mutations continue through the existing KIVRYN executor and remain approval-gated. The final OpenAI Agentic Integration is intentionally last in the ordered backlog; when that task arrives, OpenAI tool calls must target this KIVRYN-owned registry rather than gaining direct database authority.
