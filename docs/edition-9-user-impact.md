# Edition 9 user impact

Edition 9 is primarily a systems-layer release. It does not add another navigation destination. Its purpose is to make future KIVRYN agentic behavior safe and coherent: an Agent/Assistant can plan against supported workspace domains, but KIVRYN decides which actions exist, which Agent capability grants which domain, and which exact mutations the user approved.

The visible Agent/Assistant experience can be expanded in later ordered slices without duplicating backend authority or changing the user's workspace data model.
