# Phase 2 backlog captured from the Phase 1 video test

This file records product/design work explicitly deferred from the E1–E20 preflight. It does not start E21 by itself.

## Creator Studio
- Redesign the surface around a creator-first workflow with clearer hierarchy and progressive disclosure.
- Remove/move the persistent KIVI helper so it never obstructs unrelated routes or dominates the workspace.
- Put source ingestion at the top of the experience.
- A remote-video URL workflow must not be presented as functional until a real backend importer/download pipeline converts a URL source into an available storage path that Creator jobs can process.
- Add real, evidence-backed charts only when production analytics data exists; do not fake chart data.

## Community
- Improve first-run profile setup: avatar, description/bio and clearer next step.
- Make creating the user's own squad optional and easy to discover.
- Define plan-aware official community access: Free users see the free community; Premium users can access both free and premium communities.
- Revisit zero-state and squad discoverability before adding more community surface area.

## Arena
- Redesign the current functional surface to make active challenges, participation state and momentum more visually compelling without changing verified-data semantics.

## Validation carried forward
- Full Premium Agent manual/scheduled runtime validation from an authenticated Premium account.
- Creator end-to-end media ingestion and clipping runtime.
- Community profile/squad/official-community end-to-end flows.
- Arena participation end-to-end beyond the current page smoke.
